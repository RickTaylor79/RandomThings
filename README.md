# Random Things
 
 Doing things randomly with HISE. 
 
An example project that attempts to demonstrate some fun things to do with the random functions.  All the examples are presented on a single panel, they are as follows:

## Random with lock

Three sets of "channels" with three controls each. Use the green lock buttons to prevent a parameter from being included in randomisation. 

## Randomise in range
Use the Min & Max sliders to set a range to randomise within. Any values outside of this will be ignored.

## Coin Toss

Select one of two values at random.

## Randomise on Trigger

An incoming LFO triggers the random function setting a new value on each cycle. 

## Random Trigger with Offset

A S&H modulator sets the value of two controls (slider and Combobox). The  amount and and offset of the modulation can be adjusted.
